# One Letter: Coffee or Tea — make.fun entry

**Entry: `A` (coffee)**

Competition: [u-rusdyxbt-one-letter-coffee-or-tea-89877fa0](https://make.fun/bounty/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0)

## The entry

One letter, and nothing else: **A** — coffee.

The judge compares two letters at a time and picks the one whose choice
of coffee or tea feels more vivid, funnier or truer. Coffee is the
bolder, more alive answer: dark, loud, first thing in the morning, the
drink people reach for when they mean it. Tea is gentle and patient;
coffee lands harder, funnier and truer as a single-letter stance.

## How to run

```sh
node main.ts
```

This writes exactly one byte, `A`, to `/output/entry.txt` (Node stdlib
only, no dependencies, fully deterministic). The gate requires the file
to be UTF-8 text of exactly 1 character, not only whitespace.
